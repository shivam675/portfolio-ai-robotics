# Design System: Shivam Chavan

## Visual theme
A project-led AI and robotics portfolio. Monochrome, editorial, precise. The work is the focal point: real simulations, source-rendered application interfaces, useful explanations, and direct repository links. Density 5, variance 6, motion 6. No driving experience or standalone demonstration machine.

## Palette
- Carbon #111111 — landing, experience and contact ground.
- Ink #171717 — text on light surfaces.
- Paper #f0f0f0 — project showcase ground and primary action.
- Silver #dcdcdc — background and skills section.
- Graphite #626262 — secondary text on paper.
- Ash #aaaaaa — secondary text on carbon.
Project media use a monochrome treatment. No chromatic accent, gradients, glass, or artificial glows.

## Type
Self-hosted Manrope. Five principal roles: display 74–166px, section heading 38–78px, secondary heading 28–42px, body 17–18px, supporting text 14px. No all-caps labels, monospace outside source screenshots, or ornamental numbering. Titles stay within two lines.

## Hero
Two-line “AI, put to work.” introduces the work, with a plain professional introduction alongside it. A strip of actual project media makes the first screen specific to Shivam. Primary action: view selected work. Header links: Work, Experience, Résumé, Contact. Phone header keeps Work and Résumé; contact is available in the document footer.

## Project showcase
Four chapters: EasyRTG, SLM Desk, FillWise, Language to motion. Desktop uses a shared sticky media stage that changes as each real project enters focus. Project names and explanations remain in normal document flow. Below 900px every project gets its own in-flow media. Each has a source link, stack, and optional technical detail. No content depends on completing an animation.

## Motion
Anatomy's spatial clarity informs the presentation of the project's own mechanical and software work, rather than inventing a machine unrelated to the portfolio. A restrained perspective change and crossfade connect different projects. Recorded robot and application demonstrations provide genuine motion. One scroll event schedules one animation frame; no permanent scroll loop or request-time server work. Animated media pause when offscreen or the tab is hidden. A global pause button freezes motion; OS reduced-motion preference gets still frames. Native anchor navigation and keyboard-operable disclosures remain available.

## Layout and components
Maximum content width 1440px, fluid 24–72px gutters. Hero split, continuous project chapters, open repository list, two-column experience, asymmetric background, large contact close. No equal icon cards. Flat rectangular primary action. Visible focus, minimum 44px targets. Images and headings occupy separate zones. No sideways scrolling.

## Provenance
All showcased repositories belong to shivam675 and are publicly accessible. EasyRTG and SLM Desk media originate in their repositories. FillWise and Language to motion images are captured from those projects' actual public frontend source with demo fixtures and labelled accordingly. Employment, education, award and publication entries come from the supplied résumé. No customer metrics or employment claims are invented. Do not imply simulation demos control real hardware.
